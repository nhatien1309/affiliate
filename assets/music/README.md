Đặt nhạc nền (.mp3, .m4a, .wav) vào thư mục này. Agent dùng file đầu tiên theo tên, hoặc file ghi trong `brand/brand.json` ở mục `"music"`.

Chỉ dùng nhạc bạn có quyền dùng cho mục đích thương mại (ví dụ thư viện nhạc miễn phí bản quyền của YouTube Audio Library, Pixabay Music). Nhạc có bản quyền có thể khiến video bị tắt tiếng hoặc gỡ.

Không có nhạc thì video chỉ có giọng đọc.
